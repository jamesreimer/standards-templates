# Changelog

## [1.2.1] - 2026-09-28

### Changed

- Require successful local and hosted validation before implementation handoff, and align agent routing and release-planning discovery checks with publication integrity ([`903a97d`](https://github.com/jamesreimer/standards-templates/commit/903a97d44b1123793859cbbefe9ec35122b11a55), [#153](https://github.com/jamesreimer/standards-templates/pull/153))

## [1.2.0] - 2026-09-24

### Added

- Add the Publication and Release Integrity template at edition `1.0`, with adoption guidance and catalog discovery for publication correspondence, identity, verification, and correction ([`debd509`](https://github.com/jamesreimer/standards-templates/commit/debd50926ea45c371a7b10237ef9aba1b3b04304), [#152](https://github.com/jamesreimer/standards-templates/pull/152))
- Add README links showing validation status, the latest repository release, and licensing ([`cd45b81`](https://github.com/jamesreimer/standards-templates/commit/cd45b8153d856857831bacefc2ac443fb9887b90), [#151](https://github.com/jamesreimer/standards-templates/pull/151))

## [1.1.2] - 2026-09-24

### Changed

- Retain repo-template source and correspondence evidence in reconciliation PRs, replacing permanent provenance bookkeeping while preserving upstream ownership and temporary validation safeguards ([`2f05e28`](https://github.com/jamesreimer/standards-templates/commit/2f05e289fe4352c0c5a877b4731049e7964e5889), [#150](https://github.com/jamesreimer/standards-templates/pull/150))

## [1.1.1] - 2026-09-23

### Changed

- Use the complete version tag as the GitHub Release title and verify it after publication ([`df73ad3`](https://github.com/jamesreimer/standards-templates/commit/df73ad31cdbb15210ad9670d669d3c567a79a1d3), [#148](https://github.com/jamesreimer/standards-templates/pull/148))

## [1.1.0] - 2026-09-23

### Changed

- Verify exact release candidates, remote annotated tags, and partial publication state, and coordinate workflow changes with live required checks ([`a59651f`](https://github.com/jamesreimer/standards-templates/commit/a59651fc21019ee8e364627e695bded1dcf6bad5), [#146](https://github.com/jamesreimer/standards-templates/pull/146))
- Clarify in maintainer and agent guidance that reusable standards remain actor-neutral unless their subject inherently depends on a particular actor class ([`9992060`](https://github.com/jamesreimer/standards-templates/commit/99920606585d62171557a69a434c10f3eb314354), [#144](https://github.com/jamesreimer/standards-templates/pull/144))

### Added

- Introduce template editions, edition-aware adoption comparisons, and transition validation; initialize all 17 existing templates at `1.0` without changing their standard content ([`b85d2e2`](https://github.com/jamesreimer/standards-templates/commit/b85d2e2d0c1ec97630671e452eaefb7a39ffa65a), [#143](https://github.com/jamesreimer/standards-templates/pull/143))
- Define library release numbering and release-note classifications while preserving independent template identity and downstream adoption authority ([`272067b`](https://github.com/jamesreimer/standards-templates/commit/272067bd14fa9561dccbe30fd403e343f3779d0e), [#138](https://github.com/jamesreimer/standards-templates/pull/138), [`8caef60`](https://github.com/jamesreimer/standards-templates/commit/8caef60638fa632edbd460e44b154e0a6ba80596), [#139](https://github.com/jamesreimer/standards-templates/pull/139))

### Fixed

- Reject arbitrary root Markdown names even when the repository structure snapshot includes them ([`5ac1853`](https://github.com/jamesreimer/standards-templates/commit/5ac1853afcbf6a2fb493311dd77de1cb0a885942), [#145](https://github.com/jamesreimer/standards-templates/pull/145))

## [1.0.1] - 2026-09-22

### Fixed

- Point agent setup and Python version guidance to the contributor validation instructions ([`20cae71`](https://github.com/jamesreimer/standards-templates/commit/20cae71189ae84937b02817b475ee5032531262b), [#136](https://github.com/jamesreimer/standards-templates/pull/136))
