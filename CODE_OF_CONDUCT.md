# Code of Conduct

## Expected participation

Participation in this repository's issues, pull requests, reviews, and other
repository spaces should be respectful, constructive, and focused on improving
the work. Disagreement is welcome when it addresses ideas and evidence rather
than people.

Harassment, abuse, threats, discriminatory attacks, sustained disruption, and
deliberate personal targeting are unacceptable. Maintainers may edit or remove
contributions, limit interactions, or restrict participation when necessary to
protect a constructive repository environment.

## Reporting concerns

Report conduct concerns privately to the repository owner using a private
contact method listed on the owner's GitHub profile. If no private method is
available, open a brief issue asking for private contact and omit sensitive
details. Reports will be reviewed by the repository maintainer, who will take
action appropriate to the repository and the available evidence.
